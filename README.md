### Selected work

**[deep-agent-backend](https://github.com/borailci/deep-agent-backend)** · Python — graduation project
Codebase Q&A system built on LangGraph Deep Agents. RAG pipeline over Qdrant and Vertex AI with reranking, agent memory, and automatic wiki generation. Chat frontend in [deep-agent-ui](https://github.com/borailci/deep-agent-ui) (Next.js).

**[Real-Time Hand Gesture Recognition](https://github.com/borailci/EARIN_Labs/tree/main/project)** · Python, PyTorch
CNN classifying 10 hand gestures from webcam input, with MediaPipe for hand detection. 99.82% validation accuracy at under 3ms inference. Built for the Introduction to AI course at Warsaw University of Technology.

**[insider-one-devops](https://github.com/borailci/insider-one-devops)** · Go
A Go HTTP service taken through the full delivery loop: container image, Helm chart on Kubernetes, GitHub Actions CI/CD gated by Trivy, gitleaks, cosign keyless signing and Syft SBOMs, with Prometheus and Grafana on top.

**[0k-Game-on-Scroll](https://github.com/borailci/0k-Game-on-Scroll)** · Solidity, React
Onchain card game on Scroll. Hardhat contracts, React client with drag-and-drop card play, and a Socket.IO server for realtime matches.
